# Reference MIS coverage map

This map records every schedule and field of the reference net profit MIS workbook and where each one lives in this demo. The reference is a monthly divisional pack: a set of vertical sheets on one template, one category sheet that re-lists product lines sold by other verticals' engineers, two special sheets on a statutory profit and loss template, a roll-up dashboard sheet with five sections and a reasons list, and two support tables. Reference sheet and field names are given generically. Every figure in the demo is synthetic; only the structure is borrowed.

Verification evidence refers to the gates in this repository: `bun run reconcile` (cross-table assertions, published on the Data basis page), `bun run interactions` (browser gate with 37 checks), `bun run screenshots` (every route at 1440, 1024 and 390 pixels), and the desktop captures delivered with the session record.

Disposition codes: **Implemented** (present, same meaning); **Adapted** (present, period or naming adjusted for an August close, stated on the page); **Not carried** (deliberately excluded, with the reason).
